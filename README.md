# Darwin-Shop
Darwin Shop is a simple console-based C++ shopping system for PC components.

This is the first version of the project, created to practice C++ fundamentals and build a small real-world style application.

## 📌 Features

- 🖥️ GPU products
- ⚙️ CPU products
- 🧠 RAM products
- ⌨️ Keyboard products
- 🎙️ Microphone products
- 💾 SSD products
- 🖱️ Mouse products
- 🛒 Add products to cart
- 💰 Calculate the total price
- 🧾 Display the customer's order at checkout
- ❌ Exit the program

## 🛠️ Technologies

- C++
- Structs
- Arrays
- Strings
- Functions
- Loops
- Switch statements
- Basic input/output
- Basic shopping cart system

## 🎯 Project Goal

The main goal of this project is to practice C++ fundamentals by creating a simple shopping system.

This project is also the first version of a bigger idea that I plan to improve and expand in future versions.
